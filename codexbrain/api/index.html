Every brain here has an API.

Each MindBlown brain on this host is also a set of plain JSON documents: its lobes, neurons, synapses, sources, links, a graph, a search index and a feed. Any app, script, automation or AI assistant can read them. No key, no backend, no rate limit beyond the host's.

Two transports

      
Every X.json has an X.js twin. The twin wraps the same document in a call to window.MINDBLOWN_API.receive({protocol, brain, endpoint, data}), so a page on another origin can read a brain through a <script> tag even when this host sends no CORS headers. The JavaScript client switches automatically; servers and scripts use the JSON directly.

      
Page ids in paths

      
A page id such as projects/tidewatch becomes projects~2ftidewatch: letters, digits, ., _ and - stay, every other UTF-8 byte becomes ~hh. pages.json lists the ready-made api path of every page, so clients rarely need to encode anything.

      
Networks and shared neurons

      
When a host carries several brains, /api/network/v1/network.json lists them with the neuron ids they share and the peer hosts this network points at. Follow peers to walk from one MindBlown site to the next: each one has the same discovery document.

      
Writing back

      
These documents are read-only by design. A brain's manifest may name a write route: the AI Hub protocol (mindblown-ai/1) for brains that live there, or the Build module's .mindblown.json import for local brains.
