One genome, 26 brains.

This page is the index. The Network tab shows every brain on one screen (a digest: each neuron keeps up to … synapses per brain there, so a shared neuron pools that many from every brain that uses it; open a brain for all of them).

The Human genome brain is the hub: size, composition, variation, the karyotype and the road from the Human Genome Project to the telomere-to-telomere assembly and the pangenome. Each of the 24 chromosomes and the mitochondrial genome is its own brain: landmark genes, conditions mapped to it, centromere and bands, and when it was sequenced. What joins them is a set of … shared neurons in the Genome concepts, References & projects and Sequencing & methods lobes: the same id, title and definition in every brain, each brain adding its own cited synapses. Open a shared neuron in one brain and the side panel offers the same neuron in the others.

The karyotype as a network

Bars are scaled to GRCh38 length (UCSC hg38.chrom.sizes, mtDNA exaggerated to stay visible); the mark is the centromere. The number under each bar is how many shared neurons that brain contributes. Click a bar to open the brain.

The karyotype diagram needs a wider screen; the cards above open the same brains.

Shared vocabulary

Every row is one neuron id that exists in more than one brain. Each pill is a brain that uses it, with the number of synapses it contributes; the pill opens that brain on the neuron.

Only in the hub so far

Shared-vocabulary neurons that only the Human genome brain uses; the next chromosome brain that cites them lights up a connection.

Satellites

Brains that watch the genome brains rather than the genome. Monitors read the built brains and report (coverage, citations, integrity); agents propose links and facts, and what they learn is written to satellites/learned/ and picked up by the generators on the next build. Same renderer, same shared ids: a monitor's concept neuron is the same neuron as the chromosomes'.

Built from build_genome_data.py, build_chromosome_data.py <chr> (one generic generator for all 25 chromosome brains), satellites/run.py (monitors and agents) and build_network.py; mb_shared.py holds the registry of shared ids. Sizes from UCSC hg38.chrom.sizes, centromeres from UCSC centromeres.txt.
